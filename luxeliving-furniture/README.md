# LuxeLiving Furniture

LuxeLiving is a premium furniture e-commerce web app built with React, TypeScript, and Tailwind CSS. It lets customers browse and buy handcrafted furniture through a modern, animated, and fully responsive interface.

## What It Does

Users explore six categories — Bedroom, Chairs, Sofa, Dining, Office, and Storage — via the homepage, a filterable all-products page, or dedicated category listings. Each product opens to a detail page with an image gallery, quantity picker, and purchase options: Add to Cart, WhatsApp order, or phone call. A custom order page offers a guided form with image upload for bespoke requests.

## Key Features

- **Homepage** — Ken Burns hero animation, category circles, featured grid, flash sale, testimonials, and custom order CTA.
- **All Products** — Category filter pills, sort dropdown, live counts, and animated product cards.
- **Category Listing** — Banner header, item count, sort/filter controls, and product grid.
- **Product Detail** — Thumbnail gallery, quantity selector, Add to Cart, wishlist, WhatsApp order, related products, and trust badges.
- **Custom Order** — Split layout with step cards, image previews, validation, and success screen.
- **Cart & Wishlist** — Badge counters, toast notifications, and persistent state.
- **Navigation** — Sticky navbar with scroll blur, mobile menu, and quick icons.

## Design & UX

Warm stone base with brand-orange and accent-purple gradients on buttons, badges, and banners. Square product images, compact cards, and hover overlays. Transparent navbar over the hero that blurs on scroll. Smooth animations and spacing throughout.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router v7 (BrowserRouter)
- Lucide React icons
- Context API for cart, wishlist, and toasts

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5000`.
